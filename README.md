Lucky Number Game

A number guessing game where the player tries to guess a randomly generated number between 1 and 50, with feedback (too high / too low) after each guess and an attempt counter. Includes a "Play Again" option to reset and try again.

Live demo: lucky-number-game.vercel.app/luckynumber.html

Tech Stack
HTML, CSS, JavaScript (vanilla)
Deployed on Vercel
